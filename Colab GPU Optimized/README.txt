GENERATIVE AI PRACTICALS - EXPERIMENTS 01 TO 10

Contains 10 Google Colab-compatible Jupyter notebooks. Each notebook includes its own library installation cell.

How to run:
1. Extract this ZIP.
2. Open https://colab.research.google.com/
3. Upload the required .ipynb file.
4. Run cells from top to bottom.
5. Select Runtime > Change runtime type > GPU for GAN, diffusion, MusicGen and video experiments.

Important:
- CelebA may require dataset download/access approval in TensorFlow Datasets.
- Experiment 07 is an educational style-based GAN demonstration, not the complete NVIDIA StyleGAN.
- Experiment 09 uses example documents. Replace them with your own. Its LoRA cell configures adapters; meaningful fine-tuning needs a prepared dataset and training loop.
- Experiment 10 uses a large video model and may not fit on every free Colab GPU.
- Model downloads require internet access and can take time.
